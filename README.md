💱 Currency Converter

A simple and responsive Currency Converter App built with HTML, CSS, and JavaScript, that allows users to convert between multiple currencies in real-time using an exchange rate API.
<img width="1919" height="1014" alt="Currency Converter Ref" src="https://github.com/user-attachments/assets/bf9e09e1-daba-4538-998b-ef8e31ceda41" />

🚀 Features

🌐 Real-time exchange rate conversion

📱 Responsive design (works on mobile & desktop)

💻 Built with vanilla JavaScript (no frameworks)

🔄 Supports multiple currencies

🎨 Clean and easy-to-use interface

🛠️ Tech Stack

- HTML5

- CSS3

- JavaScript (ES6+)

📸 Live Demo

https://pavan7201.github.io/Currency-Converter/

📂 Installation & Setup

1. Clone the repo

git clone https://github.com/your-username/currency-converter.git
cd currency-converter


2. Open index.html in your browser — that’s it! 🎉
